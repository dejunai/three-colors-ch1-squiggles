# Chapter One intertitle squiggles (Peanuts-style)

Adult dialogue as **instrument speech** for silent-card / intertitle moments — the Peanuts animated-special register (*waa-waa*), not words.

## Instruments
- **trombone** — primary; closest to the classic muted-trombone adult voice
- **violin** — cousin set; thinner, more haunted / parlor

## Moods (10 × 2 variants)
angry · haunting · happy · cautious · dismissive · conspiratorial · pleading · bureaucratic · alarmed · weary

Each mood has `_v1` and `_v2` so repeats don’t feel identical.

## Suggested Chapter One mapping
| Mood | Likely speakers / beats |
|------|-------------------------|
| bureaucratic | Odell, clerks, official arithmetic |
| dismissive | Odell closing a door; town shrug |
| cautious | Mrs. Almy; plain-coat confidences |
| conspiratorial | barman; club talk of “her” |
| pleading | Kessler’s widow; wage-claim pressure |
| angry | Walter pushed past patience |
| haunting | Constance / entity-adjacent cards |
| alarmed | tunnel / cough recognition |
| weary | late-case Walter |
| happy | rare clean-read / tonal-contrast beat |

## Files
40 WAVs + matching MP3s. Mono, 44.1 kHz. Roughly 1–2.5s each — short enough to layer under a card, long enough to read as a “line.”

Synthesized for the project (not sampled from Peanuts). Use freely in *Three Colors of Madness*.
